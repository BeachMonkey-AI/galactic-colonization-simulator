🌌 Galactic Colonization Simulator

Von Neumann probes, the Fermi paradox, and how fast silence should become a paradox

One answer to "why haven't we found aliens?": build a robot that can fly to another star, mine raw material, build copies of itself, and send them onward. The population explodes fast enough that a single civilization could fill the galaxy in a few million years — a blink of an eye against its 13.6-billion-year history. This tool lets you test that argument yourself: tune how good the probes are and how rare civilizations are, and see whether the galaxy should already be crawling with them.

What is this, actually?

The Fermi Paradox, in one line

The universe is unbelievably old and unbelievably big, yet as far as we can tell we've never detected a single trace of anyone else in it. That mismatch — a galaxy that should be able to fill up with life, and a sky that looks completely empty — is the Fermi Paradox.

Von Neumann probes

The sharpest version of the argument uses a hypothetical machine called a von Neumann probe: a spacecraft that, on arriving at a new star system, mines raw material, builds copies of itself, and sends those copies onward. Start with one probe and the numbers explode — 2 becomes 4, 4 becomes 8 — so even a slow, unambitious probe fleet can, in principle, spread across an entire galaxy in a few million years. That's a geological eyeblink next to how long the galaxy has existed (13.6 billion years). So if that's even roughly right, the galaxy should already be full of them. It isn't, as far as we can tell. Why?

What this tool actually does

Two things decide the answer: how good the probes are at spreading (speed, how long they linger before launching children, how many children, how often they fail), and how long it takes — and how likely it is — for a planet to ever produce a civilization capable of building probes in the first place. This dashboard lets you dial in both halves and see what falls out: has anyone had time to reach us yet? If so, should we be able to detect them?

Reading the verdict

SATURATED — the numbers say probes should already be here and visible. That's a real paradox; something must be stopping this from happening.
MARGINAL — right on the edge; genuinely unclear either way.
QUIET — nobody's plausibly had time yet. No paradox, no mystery — silence is exactly what you'd expect.
DORMANT — probes should physically be here, but we might just not be able to detect them (stealthy, dormant, or we haven't looked hard enough).
STALLED — the probes' own math means they die out before ever reaching galactic scale, regardless of how much time has passed.

Physics & Math Reference

Wave Front Velocity

v_wave = d_hop / (d_hop/v + t_dwell)
Speed the colonization frontier actually advances, accounting for time spent dwelling and replicating at each stop, not just cruise speed.

Crossing Time

t_cross = 2R / v_wave
Worst-case time for the wave to cross the galactic disk — launch near the center, reach the far edge.

Replication Growth

N(t) = N₀ · (k·s)^(t/τ)
k = children per probe, s = survival per hop, τ = hop-cycle time. Occupied systems grow geometrically each generation.

Stall Condition

Expansion halts when k·s ≤ 1
Each generation produces, on average, one or fewer surviving daughters — the front dies before reaching galactic scale.

Drake-form Count

N = R⋆·f_p·n_e·f_l·f_i·f_c·L
Collapsed here to a fixed habitable-planet budget (R⋆·f_p·n_e) times the three rarity sliders, convolved over time instead of using a single L.

Metallicity Gate

Civilizations only emerge from planets formed after t_metal
Star formation before this line still happens, but doesn't leave enough heavy elements for rocky worlds.

Emergence Convolution

E(t) = SFR(t − t_bio) ⊛ N(t_bio, σ)
Emergence density is the metallicity-gated planet formation rate convolved with the biological-clock distribution.

Implied Filter Strength

filter = max(1, N_arrived · P_detect)
Factor by which the naive expected/detectable count must be suppressed to explain zero observations. Reads ~1.0× when no extra filter is needed.

Special Relativity

γ = 1 / √(1 − v²/c²)
Applied to per-probe proper time when v > 0.1c. Because 1 ly/yr = c exactly, all distance/velocity/time terms above stay unit-consistent with no conversion factor.
